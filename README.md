
# Stack Implementation in Java

## Description
This project demonstrates three implementations
of Stack using user-defined classes in Java.

## Implementations
1. Stack using Array
2. Stack using ArrayList
3. Stack using Linked List

## Operations
- Push: Insert an element
- Pop: Remove the top element
- Peek: View the top element
- Display: Display all elements

## Concepts Used
- Java Classes and Objects
- Arrays
- ArrayList
- Linked List
- LIFO Principle

## Language
Java
